| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-07 | Spoofing | OG card metadata abuse | accept | The static PNG carries no user input. Caleb's name + brand mark are public. No spoofing surface. |
| T-06-08 | Information Disclosure | description meta tag | accept | Hardcoded marketing copy, intentionally public. No PII. |
| T-06-09 | Tampering | scripts/render-og-card.mjs | mitigate | Idempotent render. Source-controlled. Anyone editing the script triggers a Caleb-visual checkpoint before next commit (this plan's pattern locks in a human-review step for brand-critical changes). |
| T-06-10 | Repudiation | OG card brand impersonation | mitigate | Custom domain (Wave 2) + Vercel-managed HTTPS cert proves provenance. Until then the Vercel subdomain is the canonical source. |

ASVS Level 1 informational. No auth, no DB, no privileged operations.
</threat_model>
