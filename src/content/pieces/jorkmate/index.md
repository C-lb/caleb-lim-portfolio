context: |
  Built at the AI Builders x Daytona HackSprint at NUS. Jorkmate treats
  the job hunt like a dating app: onboard once, then swipe through
  scored, hand-ranked roles. A right swipe spawns an AI application
  agent that assembles a tailored resume summary, cover note and
  screening answers, then submits the application in a sandboxed
  browser pipeline against real job listings - with a hard rule that
  sensitive answers (work authorisation, sponsorship, consent) are
  never guessed, only asked.
role: |
  Team build under hackathon time pressure. Owned the product concept
  and the React front end: the swipe deck with real physics, the agent
  status pipeline, deterministic match scoring, and a standalone demo
  mode that runs entirely in the browser.
outcome: |
  A working end-to-end demo in a day: live listings in, scored deck
  out, agent-submitted applications with step-by-step progress you can
  watch. The demo mode still runs anywhere with no server at all.
