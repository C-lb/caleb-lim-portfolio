context: |
  Most colour tools hand you five swatches and no reasoning. Cauldron
  picks a palette from a curated library and then shows the colour theory
  behind the pick: where each colour sits on the OKLCH hue wheel, how the
  set ranks by lightness, and which pairings actually clear a contrast
  threshold. The failures are marked in red rather than quietly passed
  over, because a palette that cannot carry body text is worth knowing
  about before it ships.
role: |
  Built the whole thing: the palette library, the harmony and contrast
  analysis, the demo interface, and the packaging that lets it run as a
  reusable skill rather than a one-off page.
outcome: |
  Public and open source, with nine named palette kits in the shelf. It
  is the tool used to pick the colour direction on the other projects
  here, including the ones in this room.
